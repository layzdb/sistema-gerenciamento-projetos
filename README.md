📌 Nota do Desenvolvedor: Minha Primeira Experiência com Programação
Este projeto marca o meu início oficial no mundo do desenvolvimento de software. 
Antes desta disciplina, eu tinha **zero conhecimento prévio em programação** e nunca havia escrito uma única linha de código. 

Toda a lógica de desenvolvimento, a criação das interfaces visuais em Java Swing e a integração com o banco de dados MySQL foram os meus primeiros passos práticos na área. Enfrentei os desafios comuns de configuração de drivers, tratamento de erros de SQL e estruturação de dados, consolidando um aprendizado do qual tenho muito orgulho.

Este sistema representa superação, persistência e o início da minha jornada técnica!
